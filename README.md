# 胃バリウム透視シミュレータ

診療放射線技師国家試験の上部消化管X線造影（胃バリウム検査）対策用の、ブラウザで動く 3D シミュレータです。
体位を変えると重力方向が変わり、硫酸バリウムとガスが胃内で入れ替わる様子と、どの壁面に二重造影像が
成立するかを可視化します。

`index.html` の 1 ファイルだけで動作します（three.js を CDN から読み込みます）。

## 4つのモード

- **学習** — 立位 / 背臥位 / 腹臥位 / 右側臥位 / 左側臥位 / 頭低位を切り替え、バリウムが流動する様子と二重造影が成立する壁面を見ます。
- **撮影手順** — 上部消化管X線検診の代表的な撮影順（食道 → 背臥位系の二重造影 → 噴門部 → 前壁 → 十二指腸 → 充盈像 → 圧迫像）を①から⑪まで。各ステップで体位が自動的に決まり、ねらいと注意点が表示されます。順に再生もできます。
- **フリー** — 操作卓のスティックで透視台の起倒角（縦方向, −30〜90°）と体軸の回転角（横方向）を、レバーで圧迫を操作します。手を離すと主要角度にスナップします。
- **問題** — 国試形式（5肢択一）の問題。選ぶと解答・解説が出て、その体位にシミュレータが自動で移動します。「像から当てる」はランダムな体位の透視像を出し、体位を当てる読影問題です。

問題文はすべてオリジナルで、実際の過去問そのものではありません。図は毎回シミュレータが描画するので、体位・胃型・造影剤量を変えれば同じ問題を別条件で確かめられます。

## そのほか

- **胃型** — 鉤状胃 / 牛角胃 / 瀑状胃 / 下垂胃。形が変わると溜まる場所も変わります。
- **造影剤・発泡剤** — バリウム投与量（0〜250 mL）とガスによる胃の拡張度。
- **体表・骨格** — 体表の透明度をスライダーで調整。脊柱・肋骨・腸骨は透視像につねに写り込み、3Dでは任意表示です。
- **視点** — 撮影台に固定した座標系で描いています。カメラは管球の位置にあり、体位を変えても動きません。台を起こしても患者と管球の位置関係は変わらず、変わるのは重力の向きだけ — 実際の透視室と同じです。初期状態は管球からの視点なので、3D と透視像がそのまま対応します。ドラッグでそこから回り込めます（管球／斜め／側面のプリセットあり）。画面左下の指標が撮影台の傾きを表します。
- **ラベル** — なし／主要／詳細の3段階。
- **シミュレーション透視像** — 3D と並べて表示、または全画面。「撮影」ボタンでフィルムとして保存し、並べて見比べられます。
- **部位別の造影状態** — 胃底部から十二指腸球部まで、充盈／二重造影／ガスの割合と判定を実時間で表示。
- **確認問題** — 国試で問われる要点 8 問。

マウスのドラッグで回転、ホイールでズーム、右ドラッグで平行移動。

## モデルの考え方

胃・食道・十二指腸を「軸に沿って断面が変化する管」としてモデル化し、体位から決まる重力方向に対して
1 次元の流体平衡を解いています。断面ごとの最下点の高さが流れの障壁になるため、瀑状胃のように胃底部が
後方に窪んだ形では「まず胃底部に溜まり、縁を越えてから胃体部へ流れ落ちる」挙動が自然に再現されます。

粘膜面へのバリウム付着は頂点ごとに保持され、一度バリウムに浸かった面はしばらく付着した状態が残ります。
「ガスに接した下側の壁が付着している」領域を二重造影域として色分けし、透視像では付着の厚みと接線方向の
壁を強調して、実際の二重造影像に近い見え方にしています。

透視像は管球を透視台に固定した幾何で描いています。体軸を回せばそのぶん斜位像になり、台を起こせばX線束も水平になります。
バリウムの厚み、粘膜への付着、接線方向の壁、軟部組織と骨の吸収差を重ねて濃度としており、実写ではありません。

数値も像もシミュレーションであり、診断や臨床判断に用いるものではありません。
