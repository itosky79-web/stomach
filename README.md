# 胃バリウム透視シミュレータ

診療放射線技師国家試験の上部消化管X線造影（胃バリウム検査）対策用の、ブラウザで動く 3D シミュレータです。
体位を変えると重力方向が変わり、硫酸バリウムとガスが胃内で入れ替わる様子と、どの壁面に二重造影像が
成立するかを可視化します。

`index.html` の 1 ファイルだけで動作します（three.js を CDN から読み込みます）。

## 4つのモード

- **学習** — 立位 / 半立位 / シャツキー位（半立位第2斜位）/ 背臥位 / 腹臥位 / 頭低位 / 右側臥位 / 左側臥位 を切り替え、バリウムが流動する様子と二重造影が成立する壁面を見ます。斜位や中間の角度はフリーモードで連続的に作れます。
- **撮影手順** — 上部消化管X線検診の代表的な撮影順（食道 → 背臥位系の二重造影 → 噴門部 → 前壁 → 十二指腸 → 充盈像 → 圧迫像）を①から⑪まで。各ステップで体位が自動的に決まり、ねらいと注意点が表示されます。順に再生もできます。
- **フリー** — 操作卓のスティックで透視台の起倒角（縦方向, −30〜90°）と体軸の回転角（横方向）を、レバーで圧迫を操作します。手を離すと主要角度にスナップします。
- **問題** — 問題は収録していません。手元の過去問を貼り付けて使います。出典・選択肢・正解・解説・体位を書いた素のテキストを読み込むと、選択式の演習になり、出典がそのまま表示されます。読み込んだ内容はブラウザに保存されます。

### 問題の貼り付け書式

```
出典: 第○回 午前 第○問
問題: 設問の本文。
1: 選択肢
2: 選択肢
3: 選択肢
4: 選択肢
5: 選択肢
答え: 2
解説: 解説の文。
体位: 0,0
---
（2問目以降は --- で区切る）
```

`体位` は「起倒角,回転角」。書いておくと、その問題を開いたときシミュレータがその体位になります（省略可）。`胃型` に鉤状胃・牛角胃・瀑状胃・下垂胃のいずれかを書くこともできます。過去問題と正答は厚生労働省が公表しています。

「像から体位を当てる」はシミュレータが描いた像から体位を答える読影練習で、国家試験の問題ではありません。

### 体位の定義について

体位の名称と角度の対応（第1斜位＝右側挙上、第2斜位＝左側挙上、シャツキー位＝半立位第2斜位 など）は、このリポジトリの実装上の定義です。教科書やガイドラインによって呼び方や角度が異なることがあるので、手元の教材と突き合わせてください。角度そのものはフリーモードで自由に作れます。

## 装置の模型

透視台は台座の上で起倒し、天板・側レール・足台がいっしょに傾きます。患者は天板の上で体軸まわりに回ります。重力はつねに真下なので、台を倒せば背中側が低くなり、起こせば足側が低くなる — この関係がそのまま造影剤の流れになります。

管球と受像器は 3D には描いていません（視界をふさぐため）。X線束の向きは台の法線に固定されていて、「管球」視点に切り替えるとその方向から見た像になります。

## モデルの考え方

胃・食道・十二指腸を「軸に沿って断面が変化する管」としてモデル化し、体位から決まる重力方向に対して
1 次元の流体平衡を解いています。断面ごとの最下点の高さが流れの障壁になるため、瀑状胃のように胃底部が
後方に窪んだ形では「まず胃底部に溜まり、縁を越えてから胃体部へ流れ落ちる」挙動が自然に再現されます。

粘膜面へのバリウム付着は頂点ごとに保持され、一度バリウムに浸かった面はしばらく付着した状態が残ります。
「ガスに接した下側の壁が付着している」領域を二重造影域として色分けし、透視像では付着の厚みと接線方向の
壁を強調して、実際の二重造影像に近い見え方にしています。

透視像は管球を透視台に固定した幾何で描いています。体軸を回せばそのぶん斜位像になり、台を起こせばX線束も水平になります。
バリウムの厚み、粘膜への付着、接線方向の壁、軟部組織と骨の吸収差を重ねて濃度としており、実写ではありません。

数値も像もシミュレーションであり、診断や臨床判断に用いるものではありません。
