# 胃バリウム透視シミュレータ

診療放射線技師国家試験の上部消化管X線造影（胃バリウム検査）対策用の、ブラウザで動く 3D シミュレータです。
体位を変えると重力方向が変わり、硫酸バリウムとガスが胃内で入れ替わる様子と、どの壁面に二重造影像が
成立するかを可視化します。

`index.html` の 1 ファイルだけで動作します（three.js を CDN から読み込みます）。

## 4つのモード

- **学習** — 立位 / 半立位 / シャツキー位（半立位第2斜位）/ 背臥位 / 腹臥位 / 頭低位 / 右側臥位 / 左側臥位 を切り替え、バリウムが流動する様子と二重造影が成立する壁面を見ます。斜位や中間の角度はフリーモードで連続的に作れます。
- **撮影手順** — 上部消化管X線検診の代表的な撮影順（食道 → 背臥位系の二重造影 → 噴門部 → 前壁 → 十二指腸 → 充盈像 → 圧迫像）を①から⑪まで。各ステップで体位が自動的に決まり、ねらいと注意点が表示されます。順に再生もできます。
- **フリー** — 操作卓のスティックで透視台の起倒角（縦方向, −30〜90°）と体軸の回転角（横方向）を、レバーで圧迫を操作します。手を離すと主要角度にスナップします。
- **問題** — 5肢択一。選ぶと解答・解説が出て、その体位にシミュレータが自動で移動します。「像から当てる」はランダムな体位の透視像を出し、体位を当てる読影問題です。

### 体位の定義について

体位の名称と角度の対応（第1斜位＝右側挙上、第2斜位＝左側挙上、シャツキー位＝半立位第2斜位 など）は、このリポジトリの実装上の定義です。教科書やガイドラインによって呼び方や角度が異なることがあるので、手元の教材と突き合わせてください。角度そのものはフリーモードで自由に作れます。

### 問題の出典について

収録している問題は**すべてオリジナル**（国試の形式に合わせて書いたもの）で、実際の過去問ではありません。各問題には出典欄があり、既定では「オリジナル問題（国試形式）／実際の過去問ではありません」と表示されます。確認できない回・問番号を書くと誤った出典になるため、意図的に付けていません。

実際の過去問を入れる場合は `index.html` の `EXAM` 配列に追記します。`src` に出典を書けばそのまま表示されます。

```js
{ q:'設問の本文。',
  c:['選択肢1','選択肢2','選択肢3','選択肢4','選択肢5'], a:1,   // a は正解の添字（0起点）
  src:'第○回 午前 第○問',                                      // 出典（省略可）
  set:[0,0],                                                    // 台の起倒角, 体軸回転角（省略可）
  type:'casc',                                                  // 胃型を指定する場合（省略可）
  e:'解説。' }
```

`set` を書いておくと、その問題を開いたときにシミュレータが自動でその体位になります。過去問題と正答は厚生労働省が公表しているので、そこから正確な番号と本文を引いてください。

## そのほか

- **胃型** — 鉤状胃 / 牛角胃 / 瀑状胃 / 下垂胃。形が変わると溜まる場所も変わります。
- **造影剤・発泡剤** — バリウム投与量（0〜250 mL）とガスによる胃の拡張度。
- **体表・骨格** — 体表の透明度をスライダーで調整。脊柱・肋骨・腸骨は透視像につねに写り込み、3Dでは任意表示です。
- **視点** — 既定は**室内**。台座つきの透視台に患者が寝ている模型を、室内の定位置から見ます。体位を変えると台が起き上がり、患者が横を向きます。カメラは動きません。**管球**に切り替えると管球の位置から見た向きになり、3D と透視像がそのまま対応します。**寄る**は胃に近づいた斜めの視点。ドラッグで自由に回り込めます。
- **ラベル** — なし／主要／詳細の3段階。
- **シミュレーション透視像** — 3D と並べて表示、または全画面。「撮影」ボタンでフィルムとして保存し、並べて見比べられます。
- **部位別の造影状態** — 胃底部から十二指腸球部まで、充盈／二重造影／ガスの割合と判定を実時間で表示。
- **確認問題** — 国試で問われる要点 8 問。

マウスのドラッグで回転、ホイールでズーム、右ドラッグで平行移動。

## 装置の模型

透視台は台座の上で起倒し、天板・管球・受像器・足台がいっしょに傾きます。患者は天板の上で体軸まわりに回ります。重力はつねに真下なので、台を倒せば背中側が低くなり、起こせば足側が低くなる — この関係がそのまま造影剤の流れになります。

## モデルの考え方

胃・食道・十二指腸を「軸に沿って断面が変化する管」としてモデル化し、体位から決まる重力方向に対して
1 次元の流体平衡を解いています。断面ごとの最下点の高さが流れの障壁になるため、瀑状胃のように胃底部が
後方に窪んだ形では「まず胃底部に溜まり、縁を越えてから胃体部へ流れ落ちる」挙動が自然に再現されます。

粘膜面へのバリウム付着は頂点ごとに保持され、一度バリウムに浸かった面はしばらく付着した状態が残ります。
「ガスに接した下側の壁が付着している」領域を二重造影域として色分けし、透視像では付着の厚みと接線方向の
壁を強調して、実際の二重造影像に近い見え方にしています。

透視像は管球を透視台に固定した幾何で描いています。体軸を回せばそのぶん斜位像になり、台を起こせばX線束も水平になります。
バリウムの厚み、粘膜への付着、接線方向の壁、軟部組織と骨の吸収差を重ねて濃度としており、実写ではありません。

数値も像もシミュレーションであり、診断や臨床判断に用いるものではありません。
